## What was built

- **PTX emission from the shared LLVM emitter** (plan-s41 option C, S52 revision in
  `docs/components/backend-nvptx/plans/plan-s41-the-nvptx-leg.md` — read the 10 amendments).
  `crates/backends/llvm/src/func/gpu.rs` is the whole realization, selected once in `emit_tiled_map`.
  Device unit = `Emission::device`, written by `emit --device-out=`; host = one call per site into
  `crates/mapal-rt/gpu/mapal_gpu.c` (driver API; kernel found by 64-bit site id; `MAPAL_PTX` env;
  `MAPAL_GPU_TRACE=1` prints per-phase ms).
- **Geometry deduced from device facts** (`profile.rs`): `Gpu` = cuDeviceGetAttribute facts;
  `gpu_tile` (FMA register tile/threads/bk), `gpu_tile_async` (cp.async stages, A pad from
  `conflict_free_pad`), `gpu_mma_tile` (TF32 mma.sync; `wide` = whole-thread register rule).
  Profiles: `cuda-ada` (4070 Ti), `rtx-4090`, `h100`, `h100-pcie`, `rtx-5090`.
- **Kernels:** naive (any affine site), FMA tile (exact face bit-identical to the oracle; contract
  face fma), TF32 tensor (`mma.sync.m16n8k8` + `cp.async`, ldmatrix A).
- **Rungs, each with a measurement-only OFF arm** (`emit --gpu-off=<rung>`): interleave, unroll,
  min-blocks, warp, prefetch, async, mma, wide, ldmatrix. TF32 face via interim `--precision=tf32`
  (ADR-0032 D5 says delete it → **ADR-0039 candidate**: bf16/f16 storage, to_tf32/to_bf16/to_f16
  morphisms, `block` fold class; NOT decided — Sapir's call).
- **Harness/infra** (`benches/gpu/`): `gen_tiles.py` (differential programs + bench sizes),
  `bundle.sh` (build everything on the Mac: PTX via Homebrew LLVM 22 `opt`/`llc`, host objects
  cross-compiled for x86-64 Linux, `libmapal_rt.a` for x86-64), `box_run.sh` (differential +
  timing), `box_profile.sh` (ptxas, SASS, nsys, host trace), `vast_run.sh` (rent → run → fetch →
  destroy; `PROFILE=1`), `tile_bench.cu` (Mapal PTX vs cuBLAS vs CUTLASS, interleaved, cudaEvent,
  L2 flush, bit-exact / TF32-bound value gate), `table.py`.

## Results (all in `benches/results-s52-gpu/`; tabulate with `python3 benches/gpu/table.py <file>`)

FP32, best shipped Mapal kernel vs cuBLAS / CUTLASS, n ≥ 2048, values bit-exact everywhere:

| part | vs cuBLAS | vs CUTLASS | file |
| --- | ---: | ---: | --- |
| RTX 4090 (sm_89) | 0.95–0.96× | 0.92–0.96× | v4-rtx-4090.txt |
| H100 PCIe (sm_90) | 0.94× (4096) | **1.05–1.06×** | v4/v5-h100-pcie.txt |
| RTX 5090 (sm_120) | 0.82–0.98× | 0.91–0.98× | v3/v5-rtx-5090.txt |

TF32 tensor: 4090 0.85–0.89× cuBLAS-TF32; 5090 0.84–0.87×; H100 0.30–0.48× (cuBLAS uses wgmma).
Differential (12 programs, both faces, all staging paths, f64, naive) **12/12 on every part, every
version.** v1 → shipped: 4090 1.2×, H100 1.5×, 5090 1.2×.

**Rung effects are per-architecture** (the reason "chosen by effect" must be per machine):
min-blocks +18–34% on Ada, −1% H100 v2 / +20% H100 v4; prefetch +30% H100, +4–15% elsewhere,
−15% at 1024; async (cp.async FMA) −8% H100, −2–3% 5090 at ≥2048, +27% 5090 at 1024; interleave
+3–13% everywhere; unroll ~0 on Ada, +4–12% Hopper/Blackwell; warp shape 0–5%.

**Gap evidence:** SASS review (FP32): Mapal issues fewer instructions/k than CUTLASS (70.8 vs 78.6,
90% FFMA) — the gap is the pipeline: register prefetch sunk late by ptxas under the 128-reg cap,
4-way bank conflict on transposed-A stores, spills on the barrier path. nsys: cuBLAS ran
`cutlass_80_simt_sgemm_256x128_8x4` (4090) and `sm80_xmma_..._128x128x8_stage3_ffma` (H100).
**Host side of a site (H100 trace, n=4096):** PTX JIT 337–688 ms per process; h2d 5.5 ms
(pageable); kernel 4.2 ms; d2h 3.2 ms of the whole 64 MB output to print one element.
**BUG: on GPU profiles the host is sequential and has no clock fence — `e2e_4096_c.host.ll:110`
reads the second clock before the GPU call at :115, so program self-timing is wrong** (the open P1
"sequential emission has no clock fence", now hit for real).

   d2h by last use; pinned memory; cubin caching (no ptxas on the Mac — build on target or cache JIT).

5. TF32: XOR swizzle / deeper stages, cross-panel fragment prefetch; FP32: 32-bit indexing, A-load lane map.
6. Canonical-tree float reduction (ADR-0028 deferred option) — the `sum` shape.
