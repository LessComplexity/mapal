# S54 streams: static fusion report of the shipped table, before (EMIT_FLAGS=--gpu-off=streams,pinned,pdl, byte-identical to
# s54-base on 45 programs x 5 parts x 2 faces) and after (shipped: streams open on the A100 and RTX 5090 only, over device-only sites; pinned and pdl off everywhere), exact face. 'on a chain stream' =
# launches with a stream index > 0; events = cross-chain waits the emitter places (the runtime adds a
# join event only when legacy work was enqueued since; it shows in the trace as op=event auto=1).
