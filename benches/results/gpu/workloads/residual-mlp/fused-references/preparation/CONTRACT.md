# Supported fused library references for the residual MLP

This isolated benchmark extends the admitted residual MLP comparison. The program remains `p=XWo; hraw=pWup; h=ReLU(hraw+b1); mraw=hWdown; m=mraw+b2; y=(p+m)/4`, with FP32 storage and the same immutable input bits, tensor shapes and requested output. Initial shapes are full tiny M16/d8/h16, then M128/d256/h512 and M128/d1024/h2048. No generic selector, recurrence, wider shape coverage or sum of primitive gains is claimed.

The new native arms are cuBLASLt unfused, cuBLASLt bias/ReLU epilogues, CUTLASS SIMT unfused, and CUTLASS SIMT bias/ReLU epilogues. Retain the existing naive, cuBLAS PEDANTIC, frozen Mapal Contract and restricted Torch controls as separately named arms when measuring on the same GPU. Historical measurements on another run are context, not paired fusion-effect evidence. A graph-enabled Torch arm is a subsequent explicit configuration, with a new cold/setup/timing record and the same gates; it is not silently substituted for the admitted CUDA-graphs-off arm.

The fused final-only DAG has three GEMM requests and the existing explicit residual/quarter pointwise kernel: p uses a plain GEMM; h uses GEMM+bias+ReLU; m uses GEMM+bias. The unfused variants use three GEMMs plus the existing bias_relu, bias_add and residual kernels. Actual internal library launch counts require executed-kernel capture; API calls are not assumed to be one hardware kernel. Residual addition and power-of-two scaling stay explicit, preserving their original arithmetic order.

## cuBLASLt descriptors

All tensor bytes remain logical row major. Each GEMM is described to cuBLASLt as column-major `Oᵀ=BᵀAᵀ`, with API dimensions N×M×K, A=logical weight B with shape N×K/ldN, B=logical activation A with shape K×M/ldK, and C/D shape N×M/ldN. Both op flags are N. This is a metadata reinterpretation, not a transpose or copy. It makes the logical output-column bias length N equal the API D row count.

Use `CUBLAS_COMPUTE_32F_PEDANTIC`, scale/data types CUDA_R_32F, host pointer mode, alpha 1/beta 0 and mandatory NVIDIA_TF32_OVERRIDE=0. Fused h sets RELU_BIAS and its b1 device pointer; fused m sets BIAS and b2. p and the unfused GEMMs use DEFAULT epilogue. Actual descriptor values, library versions, algorithm configuration and support statuses are recorded. No heuristic result, unsupported precision/epilogue, failed algorithm check or failed numeric gate triggers a precision fallback.

The column-major representation follows a real support restriction: CUDA 12.8 does not support these bias/ReLU epilogues for ROW-order D; bias length follows D rows. This is why direct row-major descriptor creation is excluded. [Official cuBLASLt epilogues and layout restriction](https://docs.nvidia.com/cuda/archive/12.8.1/cublas/index.html#cublasltmatmul).

Limit explicit cuBLASLt workspace to 32 MiB, allocated once before clocks. Query up to 8 heuristic algorithms per GEMM descriptor, check state/workspace/support, and record ID/tile/stages/splitK/reduction/swizzle/custom-option attributes. Algorithm selection/tuning occurs outside confirmation clocks and is frozen before held-out measurement. A finite coordinate sweep over whole-program configurations may tune p, then h, then m once; it is labeled as such, not global optimal selection. Every considered configuration must pass the same whole-graph numerical gates before its timing can select it.

## CUTLASS descriptors

Use the same pinned CUTLASS commit and FP32 SIMT operator class as the competitive primitive packet. Keep explicit source-audited tile configurations and the original default as a control. Compare fused/unfused implementations at identical geometry first; any separately tuned whole-program result is labeled accordingly. Compile unsupported candidates separately and preserve failures.

Plain GEMMs use LinearCombination with alpha 1/beta 0. Bias GEMMs use the existing packed bias vector as C, row-major source stride 0, alpha 1/beta 1, and output D stride N. The ReLU variant uses LinearCombinationRelu after that combination. The zero source row stride broadcasts the same N bias values to each logical row and requires source-iterator audit plus actual can_implement and full tiny gates. There is no expanded M×N bias tensor or hidden preparation inside clocks. Alpha/beta multiplication by 1 is exact for finite inputs, so the epilogue adds bias after the FP32 reduction and applies ReLU afterward. No TensorOp, lower-precision multiply, activation approximation or silent layout conversion is introduced.

Source touch sites are `cutlass/gemm/device/gemm.h:Gemm::Arguments` and initialize/run, `cutlass/epilogue/thread/linear_combination.h:LinearCombination`, `cutlass/epilogue/thread/linear_combination_relu.h:LinearCombinationRelu`, and `cutlass/epilogue/threadblock/predicated_tile_iterator.h:PredicatedTileIterator/Params`, in the existing pinned headers. Native control arithmetic is `handwritten/reference.cu:Program::gemm`, `Program::mlp`, bias_relu, bias_add and residual from the admitted packet; new code derives its separate backend plans without editing those frozen files.
