# S54 l2-raster: static fusion report, before (s54-base emitter) and after (s54/l2-raster)
# The item moves no Trm and no kernel boundary: launches, gens, h2d, d2h and host loops are
# identical before/after on every probe and part. What changes: 'L2 windows' (launches with an
# access-policy window, rung l2-window) and 'grouped kernels' (rung raster; the RTX 3090 at
# 8192-deep reductions only).
