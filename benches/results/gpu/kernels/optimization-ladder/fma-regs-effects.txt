# S53 fma-regs: ON vs OFF per rung (benches/gpu/effects.py) for every box session.
# speedup = OFF med / ON med (>1 = ON faster), 30 reps interleaved with cuBLAS/CUTLASS.
# "async" rows: the S52-shipped cp.async kernel. "sync" rows: register staging (--gpu-off=async),
# which arch-rungs ships at >=2048 on the contract face on every part, and on both faces on h100-pcie.
# Sessions: rtx-4090 (bundle2), rtx-4090-run1 (bundle1), h100-pcie (bundle2), rtx-5090 (bundle2),
# rtx-5090-run1 (bundle1). bundle1 differs only at n=1024: there it halved the wide tile, 0.70x.
# bundle2 keeps the S52 tile when the wide grid has fewer blocks than SMs. Kernels at n>=2048 are
# byte-identical between the two bundles.
# rtx-5090-throttled-host: SM at 180 MHz, cuBLAS 8192 took 201 ms. Timing discarded, differential kept.
# Four more 5090 rentals produced no data: three never left "loading" in 20 min, and one failed the ssh upload.
# Differential: 24/24 PASS in every session (12 programs x {cp.async, register staging}).
# ptxas spill gate: fma-regs-ptxas.txt.
#
# Decision (medians at n>=2048; at n=1024 the wide tile falls back to S52, so wide-fma is a no-op there):
#   rtx-4090  All four rungs ON for the contract face. Item: _c sync 1.118/1.111/1.088 (disjoint),
#             _c async 1.076/1.118/1.086; run1 1.122/1.092/1.085 and 1.085/1.090/1.094.
#             Exact face: register staging 1.065/1.058/1.048. On the cp.async path the item is ~1.0, and
#             wide-fma alone measured 0.984/0.995/0.983 (run1 0.976/0.967/0.977), so wide-fma is OFF
#             on that path.
#   h100-pcie wide-fma OFF on both faces: _c sync 0.822/0.950/1.015, _c async 0.761/0.884/0.972,
#             _exact async 0.526/0.701/0.761, _exact sync 0.750/0.897/0.971.
#             idx32+affine+pad ON for the contract face. With wide-fma off, the three together vs all
#             OFF: _c sync 1.032/1.036/0.993, _c async 1.045/1.048/1.014. Alone: pad _c sync
#             1.105/1.089/1.049; affine 1.057/1.058/1.002.
#             Exact face: those three show no gain (sync 1.005/1.000/0.999, async 0.977/0.980/0.980),
#             so they are OFF there.
#             Item as a whole is negative: _c sync 0.849/0.984/1.009.
#   rtx-5090  Contract face: item ON. It gains at 2048 and 8192 and loses 3-4% at 4096 in both
#             sessions, with overlapping ranges: _c sync 1.065/0.959/1.097 (run1 1.059/0.957/1.063),
#             _c async 1.046/0.967/1.121 (run1 1.051/1.026/1.104).
#             Exact face: the cp.async path is negative (0.930/0.917/1.049, run1 0.918/0.891/0.957) and
#             register staging shows no effect (1.019/0.983/1.015, run1 1.016/0.920/0.978), so the item
#             is OFF there. Alone, idx32, affine and pad change sign between sessions: no effect.
