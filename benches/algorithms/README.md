# Benchmark algorithms

Generated by `benches/gpu/gen_tiles.py`; `benches/gpu/bundle.sh` builds every GPU/CPU run from the same generator.
Regenerate after changing the generator, and check for drift:

```sh
python3 benches/gpu/gen_tiles.py /tmp/algos && cp /tmp/algos/*.mapal benches/algorithms/ && git diff --stat benches/algorithms
```
