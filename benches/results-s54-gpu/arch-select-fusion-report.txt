S54 arch-select: static fusion report, every probe, five parts, both faces, n = 2048 / 4096
Before = `--gpu-off=arch-select` (the part's rung table off: every rung ON, the S52 baseline);
after = the shipped table. benches/gpu/fusion_report.py (EMIT_ARGS for the OFF arm), HEAD 3aca06d.

Summary: the table changes no placement on any probe, part, face or size (launches, gens, h2d,
d2h, host loops identical). The one program whose counts differ is decode_1024_256, on every part:
the table's `retain-delta` OFF row keeps `resident` on the decode loop (2 tile + 2 gen kernels,
3 launches, 2 h2d / 2 d2h per step); with the table off, `retain-delta` takes the loop (3 tile
kernels, 5 launches, 10 h2d / 5 d2h per step: S52 round trips plus the restricted row site).
Each block below: OFF first when it differs, then ON.
